Sub-Agent System

4 vai trò chuyên trách, Main Agent điều phối — dùng đúng agent cần thiết cho quy mô task.

Live handoff
R

Researcher .agents/researcher.md

Khảo sát codebase, trace flow, tìm root cause trước khi đề xuất/chạm code — không implement. Đọc code thật trước khi tin tài liệu audit cũ. Gắn nhãn Confirmed (đã đọc file:line) hoặc Probable (suy đoán) cho mọi kết luận.

V

Reviewer .agents/reviewer.md

Gatekeeper trước khi báo "hoàn thành". Checklist 9 mục: Scope Discipline → Dependency direction → Error-handling → Auth theo route → Security → Config protection → Test integrity → Database/Performance → Naming convention.

Q

QA Testing Agent .agents/qa-testing-agent.md

Test feature/API/UI/DB/regression. Không bao giờ viết "đã test thành công" chung chung — tách riêng Build / Unit / Integration / Mock external / Real external / Real device / Manual UI.

D

Documentation Agent chưa có file

Được CLAUDE.md & README.md tham chiếu (chuẩn hoá ADR, đồng bộ docs với code thật) nhưng .agents/documentation-agent.md chưa tồn tại trong repo hiện tại.

02 Chuẩn báo cáo bắt buộc

Researcher

6 mục cố định: Phạm vi khảo sát → Kết luận (Confirmed/Probable) → Bằng chứng (file:line) → Điểm bất đồng giữa các project → Giới hạn điều tra → Đề xuất tiếp theo.

Reviewer

Mỗi finding độc lập: file, line, category, summary 1 câu, failure_scenario cụ thể, verdict CONFIRMED/PLAUSIBLE nếu có verify.

QA

Không gộp "đã test thành công". Test invariant DB (filtered unique index) phải chạy SQL Server thật, không InMemory provider.

03 4 skill nền tảng — .skills/common/

code-analysis.md

Trace request theo đúng layering — xác nhận layering thật qua ProjectReference, không đoán theo tên thư mục.

debugging.md

Kiểm tra sink log thật đang active trước khi tìm log sai chỗ. 401/403 dù có [Authorize] → nghi .AllowAnonymous() đè.

problem-solving.md

Nguyên tắc cốt lõi: smallest correct diff. Không đoán API contract/DB column khi thiếu thông tin.

permission.md

Mẫu RBAC bitmask (SubjectId, ClaimType, ClaimValue: bitmask); JWT chỉ chứa danh tính, quyền resolve lại từ DB mỗi request.

Quy ước dùng chung, đúc kết từ audit thật — mô tả target convention cho code mới, không bắt buộc rewrite code cũ.

● Thứ tự đọc rule trước khi code

Live gate order

01 Nền tảng

coding.md — Tech stack & naming convention C# · TypeScript
Backend: .NET 8/9, EF Core 8/9, MediatR 13–14, Carter 8.x, Serilog hoặc ILogger<T> thuần.
Frontend: Angular 18–21, 100% standalone, TypeScript strict, Tailwind v4, Signal API cho state mới.
  • PascalCase class/interface(I)/enum/method/property; camelCase local/param; method async luôn hậu tố Async.
  • Command/Query: <Verb><Entity>Command/Query, handler hậu tố Handler.
  • Angular: input()/output() thay @Input/@Output, OnPush, inject(), control-flow gốc @if/@for.
architecture.md — Dependency direction & layer boundary Clean Architecture
Chain đã xác nhận thật (4/7 BE: Device, Ops, ZKTime, Face):
Domain ← Contract ← Application ← { Infrastructure, Persistence } ← Presentation ← Api
  • Kiểu đặc thù hạ tầng (SqlException…) không được lộ ra khỏi Persistence/Infrastructure.
  • CIO, CSR: Endpoint→Service→DbContext trực tiếp — hợp lệ, không bắt buộc đổi.
  • Device/protocol integration (Hikvision ISAPI…) phải sau 1 interface + DelegatingHandler riêng.
security.md — Checklist hệ thống + bảo vệ config rule tuyệt đối

Không bao giờ xoá/làm rỗng/ghi đè/di dời 1 giá trị config thật mà không có chấp thuận rõ ràng cho từng lần của user. Phát hiện secret thật trong file tracked → không xoá/mask, chỉ báo path/key/tình trạng Configured/Missing và chờ duyệt.

Network & Auth
  • CORS whitelist domain cụ thể, không bao giờ AllowAnyOrigin().
  • JWT bật đủ 4 validation: Issuer, Audience, Lifetime, IssuerSigningKey.
  • Swagger chỉ Development, rate limit endpoint nhạy cảm.
Data & Query
  • Không nội suy giá trị chưa escape vào FromSqlRaw.
  • Không EnableSensitiveDataLogging() vô điều kiện; không UseLazyLoadingProxies().
  • Không log secret/PII/dữ liệu sinh trắc học thô.
workflow.md — Staged delivery, quyết định đã chốt, audit read-only
  • Giao hàng theo giai đoạn: xong 1 giai đoạn → dừng → báo cáo → chờ xác nhận.
  • Quyết định đã chốt không tự ý lật lại — cần lý do kỹ thuật, giải thích trước khi đổi.
  • Hệ thống/thiết bị thật: mặc định KHÔNG gọi API đối tác, thiết bị chấm công, DB production.

Memory & Audit

Pattern đã xác nhận & bad pattern đã audit — snapshot tại thời điểm audit, luôn grep xác nhận code thật trước khi dùng làm căn cứ.

● Vòng đời tri thức memory.md

Live audit loop

01 Pattern chung đã xác nhận

  • Result / Result<T> tại <Project>.Contract/Abstractions/Shared/Result.cs — 6/7 project (không có ở TaskFlow).
  • AsNoTracking() cho mọi read query — nhất quán ở cả 7 project.
  • Migration thủ công, không auto-migrate lúc startup.
  • Filtered unique index chống trùng/race condition ở tầng DB.
  • 100% Angular standalone component, không NgModule nào trong toàn bộ 7 FE.
